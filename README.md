# Team Heartware

An automatic medication dispenser designed to make medication management more accessible, reliable, and simple.

## Shaping Society

Heartware focuses on improving access to healthcare through a practical, scalable medication-management system.

## What We're Building

* Automatic medication dispensing
* 4-servo dispensing mechanism
* ESP32-based hardware
* Display for medication and system information
* User accounts and authentication
* Medication and schedule management
* Dispensing history and data tracking
* Bluetooth connectivity between the device and application

## Platform

The software layer manages users, medications, schedules, device data, and dispensing history. Hardware connectivity will be integrated separately.

## Goal

Build an affordable and accessible system that helps people manage medications consistently while providing a foundation for scalable healthcare technology.
